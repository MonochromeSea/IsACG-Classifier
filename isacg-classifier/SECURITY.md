# 安全说明

## 文件访问范围

应用会读取和处理你在网页设置页中选择的目录。Docker 部署时，建议只挂载需要分类和输出的目录，不要把整个系统根目录挂载进容器。

## 网络暴露

默认服务监听 `0.0.0.0:8080`，方便在局域网访问。不要直接暴露到公网。如果必须跨网络访问，请放在反向代理或 VPN 后，并自行增加认证。

## 文件处理风险

移动、复制、硬链接、软链接都可能改动输出目录内容。首次整理图库时建议先使用“复制”模式验证分类效果，再切换到“移动”模式。

## 报告问题

提交安全相关问题时，请提供：

- 影响版本或提交
- 部署方式
- 可复现步骤
- 预期行为和实际行为

请不要在公开 issue 中贴出包含隐私图片路径、访问凭据或个人数据的日志。
